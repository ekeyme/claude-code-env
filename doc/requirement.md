# ccenv 需求文档

## 背景

Claude Code 通过 `settings.json` 的 `env` 字段管理环境变量（API token、base URL 等）。当用户需要切换供应商时，直接改写 `settings.json` 会全局生效，所有已打开的 Claude Code session 都会被影响——可能正在跑的任务会突然中断。

ccenv 的核心价值：**切换只影响你选择的终端，其他终端不受影响。**

---

## 用户故事

### 核心场景

**作为** 需要在多个 Claude Code 供应商之间切换的开发者，
**我希望** 通过命名 profile 管理不同供应商的环境变量，并按需在指定终端激活，
**以便** 我可以在不同终端同时使用不同供应商，而不影响其他正在运行的 session。

### save — 快照当前配置

**作为** 刚在 settings.json 里手动配好某个供应商环境的开发者，
**我希望** 把当前配置一键保存为命名 profile，
**以便** 日后能随时恢复到这个配置，而不需要重新填写 token 和 URL。

### use — 切换供应商

**作为** 准备在新终端使用另一个供应商的开发者，
**我希望** 通过一条命令指定要用的 profile，然后在终端里 source 激活，
**以便** 这个终端用新的供应商，而其他终端不受影响。

### status — 确认当前状态

**作为** 同时开了多个终端、分别使用不同供应商的开发者，
**我希望** 一眼看清 settings.json 的官方配置和当前激活的是哪个 profile，
**以便** 我不会在错误的供应商下执行操作。

### list — 查看所有 profile

**作为** 有多个 profile 的开发者，
**我希望** 列出所有已保存的 profile 并看到哪个是当前激活的，
**以便** 我知道有哪些可用配置、现在用的是哪个。

### show — 查看某个 profile 详情

**作为** 准备切换到某个 profile 的开发者，
**我希望** 先查看它的具体内容，
**以便** 确认里面的 token 和 URL 是我想要的。

### delete — 清理不需要的 profile

**作为** 不再使用某个供应商的开发者，
**我希望** 删除对应的 profile，
**以便** profile 列表保持干净。如果删的是当前激活的 profile，自动取消激活。

### rename — 重命名 profile

**作为** 想重新组织 profile 命名的开发者，
**我希望** 给已有 profile 改名，
**以便** 名字更清晰。如果改的是当前激活的 profile，自动跟着更新。
